# fantrixx

Schlichte, mysteriöse One-Page-Website mit dem Schriftzug **fantrixx** und animiertem Nebel-Hintergrund.

## Lokal starten

```bash
npm install
npm run dev
```

Dann im Browser die angezeigte Adresse öffnen (Standard: Vite auf dem konfigurierten Port).

## Build

```bash
npm run build
npm run preview
```
